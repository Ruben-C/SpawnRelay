SpawnRelay

Clients

A client is a machine running your game servers. Add one, then run its install command on that machine.

Port forwards

Each forward opens a public port on the relay and sends its traffic through the tunnel to a port on the client machine.

API tokens

Bearer tokens for scripts and automation. See the API documentation.

Settings

Public address

The hostname or IP players and clients use to reach this relay. Leave empty to use the detected address.

Host firewall

SpawnRelay can open and close ports in this server's firewall by itself: the tunnel port, the management port and every enabled forward. Disabled or deleted forwards are closed again. Only rules tagged spawnrelay: are ever touched.

Client updates

The Clients tab shows each client's version and lets you push the server's version to it. The client fetches the binary through its own pinned tunnel, verifies the checksum and version, and restarts itself.
